# Hayyak | حياك

## Project Overview

Hayyak is a web application designed to help users discover heritage sites in Saudi Arabia and explore information about their historical and cultural significance.

## Project Objectives

- Help users browse heritage sites.
- Provide details about heritage sites, including descriptions, locations, and images.
- Allow users to search for and filter heritage sites.
- Present ratings and reviews to help users learn from previous visitors.
- Provide a simple and user-friendly interface in Arabic and English.

## Main Features

- Browse heritage sites.
- Search and filter heritage sites.
- View heritage site details.
- View ratings and reviews.
- User registration and login.
- Manage favorite heritage sites.
